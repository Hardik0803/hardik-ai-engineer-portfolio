# Hardik AI Engineer Portfolio

A personal portfolio site for Hardik Sarvaiya, an AI Engineer and Python Developer. It presents experience, technical skills, projects, education, achievements, and contact details in a responsive single-page format.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Deployment

The site is designed for GitHub Pages. After publishing, it will be available from the repository's Pages URL.
